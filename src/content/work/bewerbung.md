# Eine Bewerbung schreiben

Viele Menschen schreiben eine Bewerbung, wenn sie eine neue Arbeit suchen.

Eine gute Bewerbung enthält einen Lebenslauf und ein Motivationsschreiben.

Man sollte seine Erfahrungen und Fähigkeiten beschreiben.


## Neue Wörter

- die Bewerbung → application
- der Lebenslauf → CV
- die Erfahrung → experience
- die Fähigkeit → skill
- beschreiben → to describe


## Fragen

1. Was enthält eine Bewerbung?
2. Welche Fähigkeiten sollte man nennen?
